# EP05 · 장비 프로그램 속으로 — IronGEM.Connector (C#)

## 준비
- EP04 상태: DemoHost ↔ IronGEM COMMUNICATING · ONLINE REMOTE · 이벤트 3001 · 3002 켜짐(S2F37)
- Visual Studio 2022(**.NET 데스크톱 개발** 워크로드) · 이 레포 `ep05` 태그
- IronStudio에 SV 1004 추가 → 저장 → IronGEM 다시 시작(Monitor Stop · Start)

## IronStudio 설정 (`config/ep05.md`)
| 편집기 | 번호 | 이름 | 형식 · 단위 | 비고 |
|---|---|---|---|---|
| SV/DVVAL (**SV**) | 1004 | ProcessCount | UINT4 · (없음) | 지금까지 끝낸 공정 수 |

원격 명령(S2F41)은 IronStudio 설정이 필요 없습니다 — IronGEM이 형식만 검사하고 장비 프로그램으로 넘깁니다.

## 1부 · HelloGem (samples/HelloGem)
1. VS2022 › 새 프로젝트 › **Windows Forms 앱(.NET Framework)** · 프레임워크 4.8 · 이름 HelloGem
2. NuGet 패키지 관리 › `IronAutomation.IronGEM.Connector` 설치
3. `Form1_Load`: 이벤트 등록 → `proxy.Initialize("127.0.0.1", 5001)`
4. 버튼: `proxy.SetVariable(1001, "123.4")` → 실행 → DemoHost EP03 탭 S1F3 `1001` → 123.4
   (DemoEtcher는 꺼 둡니다 — DemoEtcher도 1001을 올립니다)

### Connector 한 장 요약
| 묶음 | API | 비고 |
|---|---|---|
| 연결 | 이벤트 등록 → `Initialize(ip, 5001)` → `Start()` | 이벤트는 Initialize를 부른 스레드로 옴. `Stop()`은 IronGEM의 호스트 통신까지 멈춤 |
| 올리기 | `SetVariable` · `SetEvent` · `SetAlarm` · `ClearAlarm` (+ `…Async`) | 반환 0 = 성공. 이벤트 전에 값 먼저 |
| 받기 | `GEMReqChangeECV`(반환 = EAC) · `GEMUserMsgReceived`(S2F41 등) | 응답 메시지는 `MakeMsg` · `AddItem` · `SendUserMsg`로 직접 |

### 시나리오
1. DemoEtcher 실행 → 운전 칸 '공정 수 (1004)' 0
2. DemoHost 탭 **EP05** → RCMD `START` → [S2F41 원격 명령] → S2F42 **HCACK 4** → 공정 시작 → S6F11 CEID 3001 → 10초 → S6F11 CEID 3002 · 공정 수 1
3. 공정 중에 다시 START → **HCACK 2**(지금은 할 수 없음)
4. RCMD `CLEAN` → **HCACK 1**(없는 명령)
5. Monitor [LOCAL] → START → **HCACK 2**(REMOTE 아님) → Monitor [REMOTE]
6. DemoEtcher를 끄고 START → IronGEM이 대신 **HCACK 2**

## 자주 막히는 곳
| 증상 | 원인 | 해결 |
|---|---|---|
| NuGet 설치 실패 '호환되지 않음' | .NET 8 · .NET Framework 4.7 이하 프로젝트 | Windows Forms 앱(**.NET Framework**) · 4.8 |
| 빌드 오류 'native gRPC asset is missing' | 패키지 복원이 덜 됨 | 솔루션 다시 빌드(패키지 복원) |
| SetVariable 결과 101 · 100 | IronGEM이 꺼져 있음(재연결을 계속 시도) | IronGEM 실행 → 저절로 붙음 |
| SetVariable은 0인데 호스트 값이 그대로 | IronStudio에 없는 VID | IronStudio 저장 → Monitor Stop · Start |
| 이벤트 핸들러에서 '크로스 스레드' 예외 | Initialize를 화면 스레드가 아닌 곳에서 부름 | 이벤트 등록 → Initialize를 Form Load에서 |
| 창을 닫았더니 호스트 연결이 끊김 | 종료 때 `Stop()` 호출 | 종료 때 Stop을 부르지 않음 |
| S2F41에 응답이 없음(호스트 T3 시간 초과) | S2F42 형식 오류(HCACK을 "4"처럼 한 자리로) | BIN은 두 자리 `"04"` |
