# EP02 · 호스트와 첫 연결 — 통신 확립과 온라인

## 준비
- IronTools v2 · IronFA 설치, IronGEM 서비스 시작(EP01)
- IronStudio › IronFA › Setting › Communication 기본값: HSMS · Device ID 0 · 127.0.0.1 : 5000 · **Passive**
- DemoHost(ep02) — `src/DemoHost/README.md`

## 시나리오
1. DemoHost 기본값 확인: 127.0.0.1 · 5000 · Device ID 0 · **Active** → [연결]
2. HSMS: Connecting → Selected (로그 `[HSMS] SelectRequest` → `SelectResponse`)
3. 통신 확립: 장비가 S1F13을 보내면 DemoHost가 S1F14(COMMACK 0)로 답함 → IronGEM Monitor Communication **COMMUNICATING**
4. [S1F13 통신 확립] — 호스트가 먼저 보내도 됨 → S1F14 COMMACK 0
5. [S1F1 Are You There] → S1F2 (MDLN · SOFTREV)
6. [S1F15 오프라인 요청] → S1F16 OFLACK 0 → Monitor Online **OFFLINE**
7. 오프라인에서 [S1F1] → S1F0 (Abort)
8. [S1F17 온라인 요청] → S1F18 ONLACK 0 → Monitor **ONLINE**
9. 한 번 더 [S1F17] → ONLACK 2 (이미 온라인)

## 자주 막히는 곳
| 증상 | 원인 | 해결 |
|---|---|---|
| HSMS가 Connecting · Retry만 반복 | IronGEM 서비스 정지 · Port 다름 · 둘 다 Passive | Monitor [Start] · Port 5000 · 호스트는 Active |
| Selected인데 COMMUNICATING이 안 됨, 로그에 S9F1 | Device ID 다름 | 양쪽 Device ID를 같게(기본 0) |
| S1F17이 거부됨(ONLACK 1) | 장비 쪽에서 오프라인으로 둠 | 장비(Monitor)에서 온라인으로 |
