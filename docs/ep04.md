## 시나리오
1. DemoHost 탭 **EP04** → [리포트 전부 지우기] → S2F38 ERACK 0 · S2F34 DRACK 0
2. [S2F33 리포트 정의] → DRACK 0 (4001 = 1001 1002 1003 · 4002 = 1101)
3. [S2F35 이벤트 링크] → LRACK 0 (3001 → 4001 · 3002 → 4001 4002)
4. CEID `3001 3002` → [S2F37 이벤트 켜기] → ERACK 0
5. DemoEtcher [공정 실행] → S6F11 CEID 3001(ProcessState 1) → 10초 뒤 S6F11 CEID 3002(4001 + 4002 ProcessTime)
6. DemoEtcher [과온 시뮬레이션] → S5F1 ALCD 0x82 · ALID 5001 → 끄면 S5F1 ALCD 0x02(해제)

## 알아 둘 점 (IronGEM 동작)
- 호스트가 정한 리포트 · 링크 · 켜기와 S5F3 결과는 IronGEM이 `Config\EventData.xml` · `AlarmData.xml`에 저장합니다 — IronGEM을 다시 시작해도 남습니다.
- IronStudio의 Report · Collection Event 편집기도 같은 파일을 씁니다. IronStudio를 연 뒤에 호스트가 리포트를 바꿨다면, **IronStudio를 다시 연 다음에** Collection Event를 저장하세요(열려 있던 옛 내용으로 덮입니다).
- IronStudio 2.0.1104의 Report 편집기는 호스트가 S2F33으로 만든 리포트를 보여 주지 않습니다(이름이 없는 리포트는 목록에 안 나옴). 호스트 정의는 `C:\IronAutomation\IronFA\Config\EventData.xml`에서 확인하세요.
