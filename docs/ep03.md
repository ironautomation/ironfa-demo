## 시나리오
1. SVID 칸 비움 → [S1F11 SV 목록] → S1F12 전체 SV 이름표
2. SVID `4` → [S1F3 SV 값] → ControlState 5(ONLINE REMOTE)
3. (설정 추가 · 재시작 뒤) SVID `1001 1002 1003` → [S1F11] · [S1F3]
4. DemoEtcher 실행 → [S1F3] 할 때마다 ChamberTemp가 바뀜
5. ECID `2001` → [S2F29 ECV 목록] → 20 ~ 200 · 기본 60
6. [S2F13 ECV 값] → 60
7. 값 `150` → [S2F15 ECV 변경] → S2F16 EAC 0 → DemoEtcher 설정 온도 150
8. 값 `250` → [S2F15] → EAC 3(범위 밖) → [S2F13] 150 그대로

## 자주 막히는 곳
| 증상 | 원인 | 해결 |
|---|---|---|
| S1F4에서 한 자리만 빈 값 | 장비에 없는 VID | 번호 확인 |
| IronStudio 칸에 빨간 테두리 | VID 중복 | 다른 번호로 |
| 새 SV가 S1F12에 없음 | 저장 후 IronGEM을 다시 시작하지 않음 | Monitor Stop · Start |
| S1F3 값이 0에서 안 바뀜 | DemoEtcher가 꺼져 있거나 IronGEM 연결 안 됨 | DemoEtcher 연결 표시 확인 |
| S2F15 → EAC 2 | DemoEtcher(장비 프로그램)가 꺼져 있어 IronGEM이 물어볼 곳이 없음 | DemoEtcher 실행 |
| S1F3 · S2F13 → S9F7 | SVID · ECID를 U2가 아닌 형식으로 보냄 | DemoHost 'ID 형식 U2' |
| 다시 녹화했더니 2001 기본값이 150 | S2F15로 바꾼 값은 ECV Default 열에 저장됨 | IronStudio에서 Default 60 → 저장 → Stop · Start |
